# SIMPATIK-Sistem-Informasi-Manajemen-Posyandu-Otomatis-Analisis-Stunting-Medik
SIMPATIK adalah platform berbasis teknologi yang dirancang untuk mendigitalkan, mengotomatisasi, dan mengoptimalkan seluruh proses manajemen data di Posyandu dengan fokus utama pada pendeteksian dini dan analisis stunting secara medik.
